# Features

Una carpeta por funcionalidad, numerada: `NNN-slug/` con `spec.md` y `progress.md`. Las crea `/f-spec`; las plantillas están en `_plantillas/`.

- El número es correlativo y no se reutiliza.
- El slug es corto, en español y en minúsculas con guiones: `001-captura-rapida-gasto`.
- La rama de trabajo se llama igual: `feat/001-captura-rapida-gasto`.
- Una feature termina cuando `/f-ship` la fusiona en `main` y marca en `progress.md` la fecha de cierre.
